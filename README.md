# Diamond Ledger

Public sports viewer and scheduled publishing workflow. Models and calculation code live in a separate private repository. All five sports update independently of the owner PC. Published timestamps indicate data age; scheduled jobs may be delayed.

Personal trial; not a commercial hosting deployment. No license to reuse the code or published material is granted.

Setup remains incomplete until Pages is enabled, ENGINE_REPOSITORY and ENGINE_SSH_KEY secrets are configured, and an online run successfully deploys the site. Static Pages does not collect usage analytics or expose an owner dashboard.
